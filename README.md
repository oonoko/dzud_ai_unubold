# 🌨️ Зудын Эрсдэлийн Систем (Dzud Risk System)

Малчдад зориулсан зудын эрсдэл таамаглах AI систем.

## 🎯 Онцлог

### Хэрэглэгчийн оруулах мэдээлэл:
- 📍 **Байршил**: Координат (lat, lon)
- 🐑 **Малын тоо**: Хонь, ямаа, үхэр, адуу, тэмээ
- 📅 **Хугацаа**: Сар (1-12)

### Системийн тооцоолол:
1. **Цаг агаарын эрсдэл** (0-100)
   - Температур (хүйтэн)
   - Салхины хурд
   - Цасны хэмжээ
   - Хур тунадас (хуурайшилт)
   - Хүйтний индекс (wind chill)

2. **Малын өртөлт** (0-100)
   - Нийт малын тоо
   - Төрөл бүрийн эмзэг байдал
   - Ямаа/хонь: эмзэг
   - Үхэр/адуу: дунд
   - Тэмээ: тэсвэртэй

3. **Эцсийн эрсдэл (Hybrid)**
   - ML модель байвал: rule-based оноо (50%) + ML зуд магадлал (50%) нэгтгэн гаргана
   - Модел байхгүй бол: Цаг агаар (70%) + Малын өртөлт (30%)
   - 4 түвшин: Бага / Дунд / Өндөр / Маш өндөр

### Хэрэглэгчид харуулах мэдээлэл:

#### 1️⃣ Эрсдэлийн дүн
- Зудын эрсдэл: 0-100 оноо
- Түвшин: Бага/Дунд/Өндөр/Маш өндөр
- Итгэлцүүр: бага/дунд/өндөр

#### 2️⃣ Газрын зураг
- Хэрэглэгчийн байршил (pin)
- Ойр орчмын сум

#### 3️⃣ Шалтгаан (Топ 3)
- "Хамгийн бага температур маш бага (-25°C)"
- "Салхи маш хүчтэй (18 м/с)"
- "Их цас орсон (12 мм)"

#### 4️⃣ Зөвлөмж
Малын төрлөөр:
- **Хонь/Ямаа**: Салхи, хүйтнээс хамгаалах байр, нэмэлт тэжээл
- **Үхэр**: Хашаа, ус/тэжээлийн нөөц
- **Адуу**: Нүүх боломжтой газар
- **Тэмээ**: Ердийн арчилгаа

## 📊 Өгөгдлийн эх үүсвэр

- **Цаг агаар**: ERA5 (Open-Meteo archive)
- **Малын тоо**: 1212.mn (Монголын статистик)
- **Хамрах хүрээ**: Өмнөговь аймаг, 2015-2024

## 🎓 AI Model

- **Загвар**: Gradient Boosting / Random Forest / Logistic Regression (хамгийн сайн нь сонгогдоно)
- **Train/test**: Жилээр салгасан (2015–2022 train, 2023+ test) — цагийн дарааллаар таамаглалт
- **Features**: 24 (температур, салхи, цас, lag, extreme flags, total_livestock, livestock_change_pct)
- **Target**: Зуд болох эсэх (малын тоо 10%+ буурах; албан ёсны зудын жил байвал `official_dzud_years.csv`-аар баяжуулна)
- **API**: `predict()` нь ML магадлалыг rule-based-тай 50/50 нэгтгэн hybrid эрсдэл буцаана

## 📋 Label баяжуулах (албан ёсны зудын жил)

`make_dataset_advanced.py` ажиллуулахдаа **official_dzud_years.csv** байвал ашиглана. Формат:

- `year`, `dzud_official` (0 эсвэл 1)
- Жишээ: `official_dzud_years.csv.example`-ийг хуулж нэр өөрчилж, ХХААХҮЯ/онцгой байдлын жилүүдийг 1 гэж бөглөнө
